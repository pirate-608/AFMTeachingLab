# AFM Teaching Lab

Unity 6000.5.7f1 / URP 17.5.0 / Windows x64 / 中文交互教学首版 0.1.0。

设计依据见 [可行性与实现方案](Docs/AFM-Teaching-Plan.md)。

## 运行

- 直接运行 `Builds/Windows/AFMTeachingLab.exe`。移动程序时需要保留整个 Windows 文件夹。
- 编辑工程：用 Unity Hub 打开本文件夹，打开 `Assets/AFM/Scenes/AFMLab.unity` 后按 Play。
- 重新生成场景：编辑器菜单 `AFM Lab > Create or refresh lab scene`。

## 三个实验

1. **光杠杆**：施加正/负外力，释放，设置光路零点；观察实际反射几何产生的探测器位移。
2. **受力与振动**：调整未变形间距、Q、有效刚度和驱动频率；查看最近一个完整振动周期、检测振幅与平均偏转历史、力—距离与势能曲线。几何视图以 0.6 周期/秒循环慢放最近周期，不代表屏幕能显示 75 kHz。
3. **闭环扫描**：稳定、过快、低增益、高增益四个预设；三个样品；中心单线往返或 64×64 二维扫描；P/I/D 实时变化。行时间与设定值用“重新扫描 / 应用”提交。关闭反馈后可手动调 Z，再切回自动控制。像素从实际 Z 位移采集，按固定色标显示真值、重建和误差，同时提供正/反扫剖面和振幅/误差历史。

顶部提供暂停、当前实验复位和演示速度。演示速度只改变时间推进量；扫描行时间才改变模型中的横向扫描速度。实际推进倍率和待计算时间会显示在顶部。右侧控件区可以滚动，关键读数始终可见。窗口默认 1600×1000，支持 1280×800。

推荐课堂顺序：在步骤 01 释放外力并设零点，再加载 10 nN；在步骤 02 从 36 nm 缓慢接近，比较振幅、相位和平均偏转；在步骤 03 先扫中心单线，再取消单线勾选，对照稳定与过快预设。光路零点与振幅设定值是两个不同的量，AM 模式反馈恢复振幅，不把每一时刻的光斑锁在零点。

## 数值约定

- q 向上为正；Z 为样品台向下的回撤位置；间距 d = Z + q − h。
- k 使用 N/m，距离使用 nm，力使用 nN，势能使用 nN·nm，时间使用秒。振子内部以 A0 与 1/ω0 无量纲化。
- 单自由度完整受迫振子＋LJ 有效势。振幅为驱动基频的零到峰值幅值，用一周期同步 Fourier 测得；扫描另有 80 μs 低通检测延迟。
- 动态实验使用理想、已标定的线性光学位移读出。与默认几何的完整一阶模态光学读出比较，±45 nm 抽样点最大相对偏差约 0.71%。这是模型简化误差，不是仪器标定精度。动态回路不模拟光路漂移或失光。
- 控制器是位置形式 PID；Z 有响应时间、行程与速度限制；包含抗积分饱和。
- 正则化势与力保持导数一致。扫描进入正则化区域会停止，不把该区当作定量结果。
- 首版假设均一刚性材料、点针尖。高度是相对平面参考的 Z 估计，不是材料参数反演。
- 光学实验以有限尺寸高斯光斑和探测器求读出；3D 结构与光路是非等比例放大示意，不参与数值计算。q、Z、h 在图示中使用同一个垂直倍率；梁挠度相对梁长放大约 667 倍。浅蓝线为局部法线。

## 与方案相比的实测调整

原方案建议扫描采用包络近似。数值实验发现不同接近路径会进入不同的 LJ 振动状态；同时独立 C# 性能测试表明完整方程在缩放仿真时钟下可用。因此首版扫描直接积分完整方程，不额外维护一个可能抹去滞回的单值查表模型。

默认每周期 128 个 RK4 步。以 256 步检查默认 k/Q/驱动下的接近路径，在间距 14、18、22、26、36、42 nm 分别检查幅值与峰值力收敛。自定义组合和非线性跳变不承诺相同误差界。显示帧率与积分步长分开；每帧计算预算不足时保留未推进的仿真时间，显示实际倍率。

渲染采用 **URP 17.5.0**、程序化网格与 UI Toolkit。Graphics 默认管线及全部 Quality 档位均使用 URP；实体材质使用 URP/Lit，激光使用 URP/Unlit，离屏视图使用 URP SingleCameraRequest。Unity 6.5 已弃用 Built-in Render Pipeline，本工程不继续依赖它。字体复用工作区 FactoryTwin 已有的中文字体资源。

## 验证与构建

```powershell
.\Tools\Verify-Core.ps1 -Full
.\Tools\Build-Windows.ps1
.\Tools\Smoke-Player.ps1
.\Tools\Smoke-Player.ps1 -Width 1280 -Height 800 -ReportFolder Reports/Layout1280
.\Tools\Write-ReleaseManifest.ps1
```

数值验证需要 .NET 10 SDK，无外部 NuGet 依赖。构建脚本需要已安装且已授权的 Unity 6000.5.7f1 和 Windows 模块。Unity 脚本/场景修改后必须重新构建，再运行播放器验收。

证据位置：

- `Reports/core-checks.json`：49 项数值与控制检查。
- `Reports/scan-matrix.json`：3 个样品 × 4 个预设的完整 4096 像素扫描。
- `Reports/approach-retract.csv`：默认力学参数、每点 500 周期、每周期 512 步、0.5 nm 间隔的接近/回撤数据。
- `Reports/build.json`：实际 Unity 构建结果。
- `Reports/player-smoke.json`：真实运行中的 UI 事件、零点、参数和完整 4096 像素扫描结果。
- `Reports/01-optical.png` 至 `06-single-line-high-gain.png`：同一运行时 UI 与相机生成的离屏截图；包含稳定、过快、二维凸起和单线对照。
- `Reports/Layout1280/`：1280×800 下同一套播放器验收和截图。
- `Reports/unity-build.log`、`player.log`：编译与播放器日志。
- `Reports/acceptance.md`：首版需求与证据对应。
- `Reports/release-manifest.json`：构建信息与源码/播放器哈希。

完整 64×64 台阶扫描：稳定预设 RMSE 约 0.146 nm，快 10 倍时约 1.726 nm，低增益约 1.529 nm，高增益约 1.414 nm。三种样品的稳定扫描 RMSE 都小于各自高度范围的 5%。这些是教学预设结果，不是仪器精度。

## 首版边界

已实现方案锁定的三步教学流程。高增益可能出现振荡和支路跳变，因此不能把每一次误差变化都解释成线性 PID 迟滞，也不能推断增益越大越好。灰色像素不参与 RMSE，误差图固定 ±2 nm 并截色；数值 RMSE 使用未截断数据。单线模式只写入中间一行，其他位置保持未采样。

FM-AFM/PLL、接触模式完整扫描、探针半径展宽、材料耗散、噪声漂移、真实压电迟滞、数据导出界面和 WebGL 均保留为后续主题。首版没有用这些未实现功能支撑测量精度结论。
